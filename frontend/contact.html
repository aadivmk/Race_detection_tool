About This Project

This tool was developed as a BTech CSE Operating Systems project to demonstrate race condition detection using static analysis and the Eraser Lockset algorithm visualization.

Course
Operating Systems — BTech CSE
Technology Stack
Python Flask + Vanilla HTML/CSS/JS + SQLite
Repository
Race-Condition-Detection-Tool

How To Run Locally

Backend (Flask)

cd backend
pip install -r requirements.txt
python app.py

Frontend

# Open frontend/index.html in your browser
# Or use a local server:
python -m http.server 8080
Tip: Make sure the Flask backend is running on port 5000 before using the Analyzer or Dashboard pages.
